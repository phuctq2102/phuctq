3. Giai nen de vao thu muc du an dang chay, giu .env.local hien tai (file ZIP khong chua .env.local).
4. Mo CMD: cd /d D:\V10_React_Supabase_Upload_Safe

   npm install
   npm run dev
5. Upload file Excel; kiem tra so dong va cac cot truoc khi xac nhan thay the.
